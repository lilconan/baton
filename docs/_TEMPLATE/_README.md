# docs/_TEMPLATE — 새 프로젝트 시작 시 복사할 문서 세트

```bash
cp -r docs/_TEMPLATE docs/{프로젝트명}
rm docs/{프로젝트명}/_README.md
```

`PROCESS.md` §8 파일 규격의 14개 문서가 전부 들어 있다. 각 문서에는
**등급 집계표 · 포화 판정 · 표본 편향 · 가정 지도 · 프리모템 표가 빈 표로 미리** 들어 있다.

> 왜 미리 넣는가 — `PROCESS.md` §8: "`0. 방법과 한계`를 맨 앞에 두는 이유 — 나중에 쓰면 안 쓴다."
> 등급 집계·포화·편향·프리모템도 같다. 빈 칸이 보이면 채우고, 없으면 아예 안 만든다.

## 문서별 특수 표

| 문서 | 미리 들어있는 표 |
|---|---|
| `1-1` | P0/P1/P2 인용 표(화자·등급·열람일 열 포함), 반복 단어 |
| `1-2` | 경쟁 서비스별 저평점 원문 건수, 아웃컴 앵커 현재값 |
| `1-3` | **아웃컴 앵커 · FIXED 표 · OPEN 가정 지도** (§2-0·§2-1·§2-1b) |
| `1-4` | 문제 후보 표 + **Reframe 판정** (§1-1) |
| `2-2` | 페르소나 도출 근거 열 (🤖 P4 금지 명시) |
| `2-3` · `3-2` · `4-1` | **프리모템 표** (§5-2) |
| `4-2` | Pain 추적 표 + 재진입 안내 |
| `9-1` | P3 / **P4 사용분** / FIXED 대가 / **프리모템 시나리오** / **미포화 리서치** 5개 절 |
| `00` | 진행 상태표에 **P0+P1 · 포화 · 프리모템 열**, **재진입 이력(↩)** 절 |

## 완료 판정

각 문서의 `0. 방법과 한계`에서 아래 세 칸이 비어 있으면 **그 문서는 완료가 아니다.**

- 리서치 실행량 (§4-1 하한 대비)
- 포화 판정 (§4-2 — 포화든 미포화든 적는다)
- 표본 편향 (§4-3 ↓편향)

그리고 `0-1 출처 등급 집계`의 **P0+P1(강등 반영)이 60% 미만**이면 기준 미달이다.
