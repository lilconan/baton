# 한국어 카피 가드레일 — 도입 배경과 적용 내역

작성일: 2026-09-11 · 대상: baton 산출물(프로토타입·문서·포트폴리오 덱)의 한국어 카피

---

## 1. 배경 — 왜 어색한가

코딩 에이전트는 토큰을 아끼려고 말을 짧게 뱉도록 세팅돼 있다. 영어는 어순이 문장의
뼈대라 좀 줄여도 뜻이 통하지만, **한국어는 조사·어미가 뼈대라 생략되면 의미가 흔들린다.**
"조사가 빠지고 명사만 뚝뚝 이어지는" 그 AI-tell(번역투)의 정체가 이것이다.

해결은 두 갈래 — **① 애초에 그렇게 안 쓰게 막기(사전) + ② 쓴 걸 고치기(사후)**. 둘 다 쓴다.

## 2. 핵심 판단 — output-style이 아니라 "에이전트 프롬프트 인라인 가드레일"

외부 도구(`fluent-korean` output-style, `im-not-ai` 등)를 그대로 도입하지 **않았다.**
결정적 이유는 output-style의 구조적 한계 하나다:

> **output style은 메인 대화에만 적용된다. 서브에이전트는 자기 시스템 프롬프트로 돌아가고,
> fork만 예외로 부모 프롬프트를 물려받는다.**

baton은 **카피를 서브에이전트가 생성한다** — `baton-builder`(프로토타입 더미 텍스트),
`baton-interpreter`(서비스 정의·페르소나), `baton-designer`(화면 텍스트). 따라서
output-style을 깔아도 **정작 카피를 쓰는 에이전트한테는 안 먹는다.** CLAUDE.md도 서브에이전트에
자동 주입되지 않는다.

→ 그래서 가드레일을 **카피 생성 에이전트의 `.md` 프롬프트 자체에 인라인으로** 박았다.
이게 서브에이전트까지 관통하는 유일한 방법이다.

또 하나의 근거 — **스타일 지시만으론 부족하다.** "자연스럽게 써" 같은 인라인 지시보다,
**초안을 별도 pass로 다시 읽고 고치는 단계를 분리하는 것 자체가 효과의 핵심**이라는 보고가
있다(한 실험에서 초안→별도 재작성 pass 추가 시 번역투가 크게 감소). 그래서 가드레일마다
**"쓴 뒤 별도 pass로 한 번 더 읽어라"**를 명문화하고, 덱에 대해서는 `deck-redteam`
에이전트를 실제 별도 pass로 돌린다.

## 3. 리서치 대조 — 문서가 말한 것 → 우리가 한 것

| 리서치 문서 | 우리 적용 |
|---|---|
| 원인: 토큰 절약 → 조사·어미 붕괴, 명사 나열 | 실제로 그 증상 교정(연결어미 뒤 쉼표·레지스터 혼용·구어 축약) |
| 해결 두 갈래(사전+사후) 둘 다 | 사후(deck-redteam) → 사전(에이전트 가드레일) 순으로 둘 다 |
| 사전 = fluent-korean(output-style) | ❌ 도입 안 함 → **에이전트 프롬프트 인라인 가드레일**(서브에이전트 관통) |
| 사후 = im-not-ai/korean-skills 스킬 | ❌ 외부 스킬 대신 **기존 `deck-redteam`을 두 번째 pass로** |
| 함정: /output-style 명령 제거(v2.1.91) | output-style 미사용이라 무관 |
| 함정: **서브에이전트 안 먹음(fork만 예외)** | ★ 인라인 가드레일의 결정적 근거 |
| 함정: **스타일 지시만으론 부족, 별도 pass가 핵심** | ★ "별도 pass로 다시 읽기"를 규칙에 명문화 + deck-redteam 분리 실행 |
| 추천: 기본 + 중요 산출물 후처리 | 기본=에이전트 가드레일 / 후처리=deck-redteam (층위 동일, 서브에이전트 구멍만 메움) |

## 4. 가드레일 규칙 (canonical)

쓴 뒤 **별도 pass로 한 번 더 읽으며** 아래를 눈으로 찾아 지운다 — "자연스럽게"만
떠올려선 안 걸린다.

- **연결어미 뒤 불필요한 쉼표 금지**: "저장해야, 다음" → "저장해야 다음" (`~듯,` 정도만 예외)
- **번역투 상투구 금지**: "~에 대해 / ~를 통해", "가지고 있다", "되어진다"(이중피동),
  "할 수 있다" 남발, "~에 있어서"
- **명사 나열 지양**: 라벨은 짧게 OK지만 안내문은 조사·어미를 살려 문장으로
  ("위치 공유 중" → "위치를 공유하고 있어요")
- **구어 축약 금지(문어 UI)**: "말 되는" → "말이 되는", "이런거" → "이런 것"
- **종결 레지스터 통일**: 한 화면/문단에서 `~해요`체·`~합니다`체·체언종결을 섞지 않는다
- **AI 클리셰 금지**: "혁신적인", "손쉽게", "원활하게", "간편하게" 남발, 과장 수식어
- **버튼·탭은 행위형 동사**: "저장", "다음", "코스 재탐색" — 명사 뭉치 금지

## 5. 적용 내역 (실제 수정 파일)

**규칙 심은 곳(사전 가드레일):**
- `.claude/agents/baton-builder.md` — §5 풀 가드레일 + 빌드 체크리스트 항목
- `.claude/agents/baton-interpreter.md` — 컴팩트판(서비스 정의·페르소나 대상)
- `.claude/agents/baton-designer.md` — 화면 텍스트·버튼 인라인 1줄
- `CLAUDE.md` — 공통 품질 체크리스트에 canonical 규칙 + 서브에이전트 인라인 근거 명시

**두 번째 pass로 실제 교정한 산출물(사후):**

  - deck-redteam이 검출: 설계 의도 문장들의 "~야," 기계적 쉼표 5연속, "말 되는" 구어 축약,
    06 sub 레지스터 혼용
  - 교정: 쉼표 제거 / "말이 되는" / 06 sub 합쇼체 통일 / STEP sub 쉼표 정리

## 6. 운영 방식

- **사전(항상)**: 카피 생성 에이전트가 자기 프롬프트의 가드레일로 처음부터 제대로 쓴다.
- **사후(중요 산출물)**: 덱은 `deck-redteam` 에이전트(축4=한국어 카피)로 별도 pass 검수.
  범용 글쓰기까지 넓히려면 그때 `fluent-korean` output-style을 메인 세션에 얹는다
  (단, 서브에이전트엔 여전히 안 먹으니 가드레일이 본체).

## 7. 정직·검증 노트 (프로젝트 규칙 7)

리서치 문서의 수치(도구 별점·논문 AUC·번역투 감소율 등)는 **원문을 직접 열어 확인한 값이
아니라 그 문서의 주장**이다. 따라서 **방향만 채택하고 수치는 산출물에 인용하지 않는다.**
외부 플러그인을 실제로 설치할 경우, 그 시점에 레포 실존·최근 커밋·라이선스를 먼저 검증한다.

## 9. 2026-09-12 개정: 프롬프트 지시에서 실행되는 아키텍처로

§2·§5의 인라인 판단 위에, 실제로 실행되는 층을 얹어 승격했다. 전제 하나도 바로잡았다.
**CLAUDE.md는 non-fork 서브에이전트에 상속된다**(Explore·Plan만 예외). 상속되지 않는 것은
output-style이다. 다만 baton은 남의 머신에 설치돼 그쪽 프로젝트에서 돌기 때문에, baton의 CLAUDE.md는
그 세션에 실리지 않는다. 그래서 배포까지 함께 가는 SSOT는 CLAUDE.md가 아니라 스킬로 두는 것이 맞다.

| 구분 | 이전 | 지금 | 이유 |
|---|---|---|---|
| 가드레일 위치 | 세 에이전트에 인라인 복붙 3벌 | `korean-copy-guardrail` 스킬 1개(SSOT) + 세 에이전트 frontmatter `skills:` 주입 | 드리프트 제거, 배포까지 함께 감 |
| .md 산출물 | 눈으로 재독(강제 없음) | `hanlint hook` PostToolUse로 저장 때 자동 검사 | 지시가 아니라 실행 |
| 대화창 답변 | 장치 없음 | fluent-korean output-style(전역) + `hanlint hook --reply` Stop 훅 | 1차 방어에 사후 그물을 더함 |
| 덱·프로토타입 HTML | 자동 검사 대상 아님(hanlint는 .md만 봄) | `.claude/hooks/deck-korean-check.js`로 카피를 뽑아 `hanlint - --preset chat` | HTML 카피도 커버 |
| 기존 문서 폭주 | 해당 없음 | `hanlint baseline`으로 90개 글 1582건 잠금, 신규만 노출 | 첫날 폭주를 막음 |

적용 파일: `.claude/settings.json`(훅 3종), `~/.claude/skills/korean-copy-guardrail/SKILL.md`,
`~/.claude/output-styles/fluent-korean.md`, `.claude/hooks/deck-korean-check.js`,
`hanlint.toml`과 `.hanlint-baseline.json`, 세 에이전트와 CLAUDE.md(인라인 제거 후 스킬 참조).

미적용(후속 과제): SubagentStop 강제 게이트, 타 머신 배포용 `install.sh` 반영,
LLM 윤문기(im-not-ai / korean-skills). 근거는 외부 리서치 회신(2026-09-12, `~/Downloads/baton-한국어-고도화-리서치.md`)이다.
